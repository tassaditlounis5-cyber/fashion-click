# FASHION CLICK : site e-commerce de vêtements

Site web de vente de vêtements (homme, femme, enfant) réalisé en **HTML, CSS et JavaScript**, sans base de données. Projet de démonstration front-end.

**Site en ligne :** https://tassaditlounis5-cyber.github.io/fashion-click/

## Pages du site

| Page | Fichier | Contenu |
|---|---|---|
| Accueil | `pageaccueil.html` | Bannière, produits tendance, avis client, nouveautés, contact |
| Promotions | `pagepromotion.html` | Soldes jusqu'à -50 %, code promo, avis des clients |
| Commande | `pagecommande.html` | Catalogue, quantités, panier, options de paiement, formulaire de livraison |
| Authentification | `pageauthentification.html` | Formulaire de connexion |
| Inscription | `pageinscription.html` | Formulaire d'inscription complet |
| Produits | `pageproduit.html` | Catalogue par catégorie (homme, femme, enfant) et panier |

## Fonctionnalités

- Menu de navigation, avec menu mobile sur petits écrans
- Compteur de panier et choix des quantités
- Code promo (essayer `PROMO10`)
- Validation des formulaires : format de l'e-mail, mots de passe identiques, âge, conditions acceptées
- Affichage des produits par catégorie en JavaScript
- Icônes Boxicons

## Technologies

- HTML5
- CSS3 (Flexbox, Grid)
- JavaScript (sans framework)
- [Boxicons](https://boxicons.com/) pour les icônes

## Lancer le site en local

1. Télécharger le dépôt (bouton vert **Code** puis **Download ZIP**).
2. Extraire le dossier.
3. Ouvrir `index.html` dans un navigateur.
