COMMENT UTILISER
1. Copiez tous ces fichiers dans votre dossier "site web" (celui qui contient deja vos images).
2. Windows demande de remplacer les fichiers : choisissez "Remplacer".

(Ce ZIP ne contient pas les images : gardez les votres dans le dossier.)
